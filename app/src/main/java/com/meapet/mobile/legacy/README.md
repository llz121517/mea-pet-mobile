# 旧版兼容迁移模块 · 纪律

本包是**一次性兼容代码**，不是业务模块，不提供长期 API。所有改动必须遵守：

1. **一个迁移操作一个文件**：放在 `steps/` 下，实现 `LegacyMigrationStep`，并注册到 `LegacyMigration.STEPS`。
2. **只做「检测旧数据 → 删除 / 重置」**：不得新增业务逻辑，不得依赖新功能代码，不得借机塞入其它需求。
3. **业务代码禁止直接引用本包**：唯一调用方是 `AppContainer.warmUp()`；组件之间不得通过本包通信。
4. **每步必须幂等**：可重复执行；失败只记日志，不阻塞启动、不影响其它步骤。
5. **迁移命中时必须同步收敛状态**：例如清理旧版 TTS 数据后，要一并关闭主界面/悬浮窗两个语音开关，避免出现"开关开着但模型不在"的错觉。
6. **新增迁移的固定动作**：`steps/Xxx.kt` + 注册 `STEPS` + JVM 单测（临时目录 / mock），不修改业务模块。
7. **删除时整包移除**：到期后整包删除，并同步清理外部调用点、测试与文档。
